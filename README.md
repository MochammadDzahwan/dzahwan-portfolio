# Mochammad Dzahwan Fadhloly — Creative Portfolio

A high-performance, futuristic **Cyber-Bento** personal developer portfolio engineered with **React 18**, **TypeScript**, **Tailwind CSS**, and **Vite**.

## ✨ Key Features & Creative Highlights

- **Futuristic Cyber-Bento Aesthetic**:
  - Deep cyber slate palette (`#06090e`) with electric emerald (`#10b981`), cyan, and ambient radial glow mesh.
  - Glassmorphic bento containers with micro-border interactions and hover elevation.
  - Holographic Developer HUD card with scanlines, orbital rings, and dynamic status tags.
- **Interactive Developer Terminal / Command Palette**:
  - Full CLI emulator with typing prompt (`dzahwan@dev:~$ `), history navigation (Arrow Up/Down), command chips, and execution.
  - Supports commands: `help`, `about`, `experience`, `projects`, `skills`, `contact`, `download-cv`, `sudo hire`, `clear`.
  - Global keyboard shortcut: **`Cmd + K`** (or `Ctrl + K`) to launch instantly from anywhere on the page.
- **Interactive Project Case Study Modals**:
  - Deep-dive technical drawer/modals highlighting the problem statement, engineering architecture, and impact for all 6 projects (WTI Crude Oil LSTM, NLP Guest Request Triage, SIPS Archiving System, etc.).
- **Live Jakarta (WIB / GMT+7) Real-Time Clock**:
  - Ambient header showing real-time Jakarta time and active availability status.
- **Quick Actions & Micro-Interactions**:
  - One-click copy email address with instant toast confirmation.
  - Direct CV download link (`/Mochammad-Dzahwan-Fadhloly-CV.pdf`).
  - Interactive email dispatch composer.

## 🚀 Requirements & Quick Start

Requires **Node.js 18+ or 22+** (an `.nvmrc` file specifying `v22.23.3` is included).

```bash
# If using nvm
nvm use

# Install dependencies (if not already installed)
npm install

# Start development server
npm run dev
```

## 🏗️ Production Build

```bash
npm run build
npm run preview
```

## 🌐 Deploy to Vercel / Netlify

1. Push this repository to GitHub or GitLab.
2. Connect the repository in Vercel or Netlify.
3. Framework preset: **Vite**
4. Build command: `npm run build`
5. Output directory: `dist`
